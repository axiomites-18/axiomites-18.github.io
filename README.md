# PUST ICE 18th Batch: student profiles

Plain HTML, CSS and JavaScript. No build step.

## Put it online with GitHub Pages
1. Create a new repository on GitHub.
2. Upload everything in this folder (index.html, style.css, script.js, data.js and the images folder) to the repository root.
3. Go to Settings > Pages, set Source to "Deploy from a branch", choose `main` and `/ (root)`, then Save.
4. After a minute the site is live at https://YOUR-USERNAME.github.io/REPO-NAME/

## Editing
- Student details: edit `data.js`.
- Add or change a photo: put the file in `images/students/` and set the student's `photo` path in `data.js`.
- Hide phone numbers on the public site: set `SHOW_PHONE = false` at the top of `data.js`.
